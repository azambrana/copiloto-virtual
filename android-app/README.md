## Prerequisitos

Todos los instaladores se encuentran en el directorio `instaladores` en la raíz del proyecto `copiloto-virtual`.

### Software
1. Android Studio Ladybug | 2024.2.1 Patch 3
2. JDK Java 21, Eclipse Adoptium 

### Hardware
1. Computadora con sistema operativo Windows 11
2. Dispositivo móvil con sistema operativo Android 11+ (Opcional)
3. Conexión a internet
4. Cable USB-C
5. WebCam
6. Red WiFi entre la computadora y el dispositivo móvil (Opcional)
7. Soporte para el dispositivo móvil (Opcional)

## Pasos para ejecutar el proyecto

1. Clonar el repositorio
2. Abrir el proyecto en Android Studio, esperar a que sincronice las dependencias y construya el proyecto
3. Proceder a ejecutar el proyecto en un dispositivo móvil con sistema operativo Android 11+ o en un emulador de Android Studio

## Cómo testear el proyecto

1. Abrir el proyecto en Android Studio
2. Ejecutar el proyecto en un dispositivo móvil con sistema operativo Android 11+
* Si no se tiene un dispositivo móvil, se puede utilizar un emulador de Android Studio
* Para utilizar un emulador, se debe crear un dispositivo virtual con las siguientes características:
  - Modo: Horizontal
  - WebCam: Habilitada
3. Probar las funcionalidades del proyecto, utilizando cualquier método de testeo
* Se puede utilizar la cámara del dispositivo móvil o la cámara del emulador para probar las funcionalidades en video o imagen con señales de tránsito
* Utilizar el soporte para el dispositivo móvil para mantenerlo en posición horizontal en Avenidas y Calles de la ciudad
* Utilizar el dispositivo móvil conectado a la computadora con un cable USB-C para probar la aplicación utilizando la cámara del dispositivo móvil
* Utilizar la red WiFi para probar la aplicación en un dispositivo móvil conectado a la red WiFi de la computadora y la cámara del dispositivo móvil
4. Verificar que no existan errores en la consola de Android Studio
5. Verificar que no existan errores en la consola del dispositivo móvil
